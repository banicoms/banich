# بانیچ — Banich 6.0

افزونهٔ فارسی‌خوان Chrome و Firefox

## امکانات
- راست‌چین‌کردن پاراگراف‌های فارسی، عربی، کردی سورانی، دری و پشتو؛ حفظ جهت پاراگراف انگلیسی.
- انتقال علامت و شمارهٔ فهرست‌های فارسی به راست؛ تشخیص مستقل موارد و زیر‌فهرست‌ها.
- اعمال فونت وزیرمتن روی پاراگراف‌های هدف با فونت‌های محلی.
- حفظ جهت چیدمان، پنجره‌ها و containerهای flex/grid.
- تنظیم مستقل فونت و RTL برای هر سایت، پشتیبانی از متن داینامیک و iframeهای مجاز.
- چهار تم و انیمیشن آیکون.

## نصب Chrome
1. صفحهٔ `chrome://extensions` را باز کنید.
2. Developer mode را روشن کنید.
3. Load unpacked را بزنید و پوشهٔ `dist/banich-chrome` را انتخاب کنید.

## نصب موقت Firefox
1. صفحهٔ `about:debugging` را باز کنید.
2. This Firefox و سپس Load Temporary Add-on را انتخاب کنید.
3. فایل `dist/banich-firefox/manifest.json` را باز کنید.

نصب دائمی در Firefox معمولی نیازمند امضای افزونه است. پس از به‌روزرسانی افزونه، صفحات باز را یک‌بار Refresh کنید.

## ساخت و بررسی
```bat
build.bat
node tools/check.cjs
node --check content.js
npx --yes web-ext lint --source-dir dist/banich-firefox --output json
```

تست رفتاری مرورگر:
```sh
python -m http.server 8769 --bind 127.0.0.1
```
سپس `http://127.0.0.1:8769/tools/check-browser.html` را باز کنید. نتیجه باید `PASS` باشد.

## حریم خصوصی
تنظیمات فونت، جهت و تم در storage محلی مرورگر ذخیره می‌شوند. افزونه سرویس آمارگیری ندارد؛ فونت‌ها همراه مجوزهای OFL داخل بسته قرار دارند.

## محدودیت‌ها
صفحات محافظت‌شدهٔ مرورگر، متن canvas، closed shadow roots و ویرایشگرهای rich-text پوشش کامل ندارند. زبان پاراگراف با نخستین حرف قوی تشخیص داده می‌شود. فونت هدف فعلاً وزیرمتن است.

## نسخهٔ ۶.۰
نهایی‌سازی نسخه، هماهنگی manifestها و رابط، مستندات به‌روز، راست‌چین پاراگراف و اصلاح علامت فهرست‌ها. جزئیات در `docs/CHANGES_SUMMARY.md`.
