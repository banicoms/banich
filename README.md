# Banich 4.0.1 🚀

**Banich** یک افزونه متن‌باز برای مرورگرهای مبتنی بر Chromium است که خوانایی وب را برای فارسی‌زبان‌ها بهتر می‌کند. نسخه **4.0.1** علاوه بر بهبود سرعت و دقت، دوباره **بنر تبلیغ یک‌باره پس از نصب** را برگردانده و حالا از **Options Page**، **allowlist / exclude list** و **تنظیمات کامل‌تر برای هر دامنه** پشتیبانی می‌کند.

## امکانات اصلی

- اعمال **فونت فارسی Vazirmatn** به‌صورت **محلی** و بدون وابستگی به Google Fonts
- اعمال **RTL** فقط روی عناصر متنی رایج و امن
- حفظ حالت طبیعی برای فیلدهای حساس مثل **email / url / tel / password**
- نادیده گرفتن **کد، ادیتورها، SVG، canvas و آیکون‌ها**
- مدیریت **allowlist** و **exclude list**
- تنظیمات **پیش‌فرض** و **override اختصاصی برای هر قانون**
- نمایش **تبلیغ فقط یک بار بعد از نصب** در popup
- درخواست **مجوز دامنه‌محور** فقط برای سایت‌هایی که کاربر تعیین می‌کند

## تفاوت‌های مهم نسخه 4.0.1

- بازگشت بنر تبلیغ یک‌باره در popup
- اضافه شدن **Options Page** برای مدیریت پیشرفته
- اضافه شدن **allowlist / exclude list**
- امکان ذخیره **تنظیمات per-site کامل‌تر** برای قوانین allow
- بهینه‌سازی منطق background برای کاهش injectهای غیرضروری و بهبود سرعت
- حفظ فونت محلی و حذف وابستگی به فونت خارجی

## نحوه استفاده

### از Popup

1. روی آیکون افزونه کلیک کنید.
2. برای سایت فعلی روی **فعال‌سازی برای این سایت** بزنید.
3. در صورت نیاز می‌توانید همان‌جا سایت را به **استثنا** اضافه کنید.
4. برای تنظیمات پیشرفته روی **تنظیمات پیشرفته** بزنید.

### از Options Page

در صفحه تنظیمات می‌توانید:

- allowlist و exclude list را مدیریت کنید
- برای هر قانون allow مشخص کنید:
  - فونت از پیش‌فرض پیروی کند یا روشن/خاموش اجباری باشد
  - RTL از پیش‌فرض پیروی کند یا روشن/خاموش اجباری باشد
- دامنه‌های دقیق یا الگوهای کلی مثل `*.example.com` تعریف کنید

## محدودیت‌ها

- افزونه روی صفحه‌های داخلی مرورگر مثل `chrome://` یا وب‌استور کروم اجرا نمی‌شود.
- اگر سایتی iframeهای cross-origin داشته باشد، ممکن است بعضی بخش‌ها تحت تأثیر قرار نگیرند.
- هدف افزونه **بهبود خوانایی** است، نه ترجمه یا بومی‌سازی کامل سایت.

## ساختار پروژه

- `manifest.json` — پیکربندی افزونه و نسخه 4.0.1
- `background.js` — مدیریت تب‌ها، آیکون و اعمال هدفمند تنظیمات
- `content.js` — کتابخانه مشترک state، rules و helperها
- `page.css` — استایل اصلی اعمال‌شونده روی صفحات
- `popup.html` / `popup.css` / `popup.js` — popup افزونه و تبلیغ یک‌باره
- `options.html` / `options.css` / `options.js` — صفحه تنظیمات پیشرفته
- `assets/fonts/` — فونت محلی Vazirmatn به‌همراه فایل لایسنس آن (`OFL.txt`)
- `scripts/` — اسکریپت‌های بررسی و تست ساده

## توسعه و بررسی کیفیت

```bash
npm run check
```

این دستور این موارد را بررسی می‌کند:

- درستی ساختار فایل‌ها و manifest
- نسخه `4.0.1`
- نبود وابستگی به فونت خارجی
- صحت helperهای اصلی و الگوهای دامنه

## نصب دستی

1. مخزن را کلون کنید:

   ```bash
   git clone https://github.com/banicoms/banich.git
   ```

2. به `chrome://extensions` بروید.
3. **Developer mode** را فعال کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشه پروژه را انتخاب کنید.

## لایسنس

این پروژه تحت لایسنس **MIT** منتشر شده است. فونت Vazirmatn نیز با فایل مجوز خودش در `assets/fonts/OFL.txt` قرار دارد.
